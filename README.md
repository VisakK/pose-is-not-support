# Pose Is Not Support

Project page for *Pose Is Not Support: Do Learned Whole-Body Controllers Follow Revised Support Commands?*
(Visak Kumar; submission to the CoRL 2026 Workshop on Open Problems in Contact-Rich Loco-Manipulation).

Live at https://visakk.github.io/pose-is-not-support/

- `index.html`: the page (static, no build step)
- `assets/pose_is_not_support.pdf`: the paper
- `assets/video/`: the supplementary video (1080p, H.264) and the teaser loop
- `assets/img/`: figures from the paper and the video poster

All results are in simulation (Isaac Lab / PhysX).
